# concept-learner（概念学习资料生成）

## 这个 Skill 是做什么的

接收一个「概念」作为学习主题，自动产出一份结构化的学习资料（默认 Markdown，可指定 HTML），帮助使用者从「知道名字」推进到「能解释、能应用、能辨别边界」。

它不是为某个具体概念写死的一次性提示词，而是一套可复用的流程：换成任何概念（Agent、上下文、微调、RAG、Transformer……）都能按同一套步骤产出。

## 适用场景（何时调用）

- 用户想学习或复习一个新概念。
- 用户要求「帮我整理 / 总结 / 讲解 X」。
- 用户想建立个人知识库或课程笔记。

不适用：纯翻译、纯代码编写、以及与「概念学习」无关的一次性问答。

## 输入信息

1. **概念名称**（必填）：要学习的概念，中英文均可。
2. **目标读者 / 深度**（可选）：默认「入门到中级」；可指定「零基础 / 进阶 / 面向面试」。
3. **输出格式**（可选）：默认 Markdown；可指定 HTML、纯文本。
4. **已有资料或偏好**（可选）：用户已有笔记、或想重点展开的某个维度。

## 生成步骤

1. **确认主题**：明确概念的中英文名与所属领域，消除歧义（例如 "Agent" 在不同语境含义不同）。
2. **建立个人理解**：先用一两句话给出「个人解释」，必须用自己的话，不能整段照搬定义。
3. **拆解核心机制 / 组成**：列出该概念的关键组成、运行原理、核心概念链。
4. **给出具体应用场景**：至少 1 个真实、具体的场景，说明「谁、在什么情况下、怎么用它」。
5. **辨析易混淆点与边界**：指出常被混用的概念、常见误区，以及「什么时候不该用它」。
6. **设计自测题**：给出 3–5 个能检验理解的问题，可附参考答案或提示。
7. **整理可核查来源**：列出真实存在、可点击核验的资料来源链接，禁止伪造。
8. **自检并交付**：按下方「自检要求」逐项核对后再输出。

## 输出结构（默认）

对每个概念产出一份资料，建议按以下小节组织：

1. 概念的一句话个人解释
2. 核心机制 / 组成
3. 一个具体应用场景
4. 容易混淆的问题 / 使用边界
5. 自测问题
6. 资料来源链接（可核查）

## 资料来源要求

- 只引用真实存在、可公开访问的链接（官方文档、论文、权威博客、开源仓库）。
- 每个关键论断尽量有来源支撑；不确定的内容标注「待核实」。
- 严禁编造链接或论文标题。

## 自检要求

交付前逐项检查：

- [ ] 个人解释是「自己的话」，没有整段照搬原文。
- [ ] 核心机制 / 组成准确，没有把相关但不同的概念混为一谈。
- [ ] 应用场景具体、可想象，而非空泛口号。
- [ ] 易混淆点 / 边界写清楚了「是什么」和「不是什么」。
- [ ] 每个来源链接真实可访问、与内容对应。
- [ ] 语言清楚，术语首次出现时有解释。

## 示例

输入：「帮我用 concept-learner 学习『大模型的上下文』」。

输出：一份包含上述 6 个小节的学习资料。
